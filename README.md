Catalogue photo of the PIZZA REWINDER: slices go in on the left, a whole pizza comes out on the right.

## Run

- `python3 tools/prepare.py` (needs Pillow) turns `assets/source.png` into a 1024x1024 JPEG at `assets/entry.png`.
- `python3 main.py` checks that file and copies it to `entry.png` in `$MAKEFUN_OUTPUT_DIR` (default `/output`). It uses only the standard library.
